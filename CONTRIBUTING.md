# Contributing to Awesome AI Skills

Thank you for your interest in contributing! This list aims to be the most comprehensive and high-quality collection of AI agent skills.

## Guidelines

### Adding a new skill

1. Make sure the skill is **actively maintained** (updated within the last 6 months)
2. The skill should work with at least one major AI coding agent (Claude Code, Cursor, Copilot, Gemini CLI, etc.)
3. Add your entry in the correct category, maintaining alphabetical order
4. Use the format: `| [Skill Name](URL) | Stars/Info | One-line description |`
5. Keep descriptions concise (under 80 characters)

### Quality standards

- No spam or self-promotional content without genuine value
- Skills must have clear documentation
- Prefer skills with SKILL.md or AGENTS.md files
- Include star counts for GitHub repositories

### Suggesting a new category

Open an issue first to discuss the new category before submitting a PR.

## Code of Conduct

Be respectful and constructive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/).
