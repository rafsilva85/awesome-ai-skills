## How to Claim

1. Comment on the issue for the bounty you want to claim
2. Build the skill following our [Skill Creator Guide](https://skillflow.builders/docs/create)
3. Submit a PR with your `SKILL.md` file
4. Our team reviews and scores the skill
5. If accepted (Trust Score ≥ 80), you receive the bounty!

## Requirements

- Skill must include a complete `SKILL.md` file
- Must pass the [SkillFlow Linter](https://github.com/rafsilva85/skillflow-linter)
- Trust Score must be ≥ 80
- Must include tests or usage examples
