# Awesome AI Skills [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of the best AI agent skills, plugins, and extensions across all major platforms. Skills are reusable, portable packages that give AI coding agents specialized expertise.

**What are AI Skills?** Skills are instruction files (typically `SKILL.md`) that give AI agents domain-specific knowledge and capabilities. They work across Claude Code, GitHub Copilot, Cursor, Gemini CLI, Windsurf, and more.

Maintained by [SkillFlow](https://skillflow.builders) — The curated marketplace for AI agent skills.

## Contributing

Contributions welcome! Please read the [contribution guidelines](CONTRIBUTING.md) first.

### How to add a skill

1. Fork this repository
2. Add your skill to the appropriate category
3. Include: Name, link, star count (if applicable), and a one-line description
4. Submit a Pull Request

### Quality criteria

- The skill must be actively maintained
- It should have clear documentation (SKILL.md or equivalent)
- It must work with at least one major AI coding agent
- No spam, low-quality, or duplicate entries
