# 🏗️ SkillFlow Hackathon Challenge

## Build the Next Great AI Skill

We're challenging developers to build innovative AI agent skills and submit them to SkillFlow.

### The Challenge

Build an AI skill that solves a real problem. The best submissions will be:
- Featured on the SkillFlow homepage
- Promoted in our "Skill of the Week" newsletter
- Eligible for bounty rewards

### Categories

1. **Productivity** — Skills that save time on repetitive tasks
2. **Developer Tools** — Skills that improve the coding workflow
3. **Research** — Skills that automate information gathering
4. **Creative** — Skills for content creation, design, or media
5. **Wild Card** — Surprise us!

### How to Participate

1. Fork the [awesome-ai-skills](https://github.com/rafsilva85/awesome-ai-skills) repo
2. Create your skill with a `SKILL.md` file
3. Test it with the [SkillFlow Linter](https://github.com/rafsilva85/skillflow-linter)
4. Submit a PR to the awesome-ai-skills repo
5. Tag your PR with `hackathon`

### Prizes

| Place | Prize |
|-------|-------|
| 1st | $500 + Featured on homepage for 1 month |
| 2nd | $250 + Skill of the Week feature |
| 3rd | $100 + Badge on profile |
| All valid submissions | SkillFlow Verified Creator badge |

### Timeline

- **Submissions open:** Now
- **Deadline:** April 30, 2026
- **Winners announced:** May 7, 2026

### Judging Criteria

- **Usefulness** (30%) — Does it solve a real problem?
- **Quality** (25%) — Trust Score from SkillFlow Linter
- **Innovation** (25%) — Is it creative and novel?
- **Documentation** (20%) — Is the SKILL.md complete and clear?
